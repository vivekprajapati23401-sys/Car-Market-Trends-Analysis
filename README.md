# Car Market Trends Analysis with Car Dekho Data

## Project Overview

This project focuses on analyzing Car Dekho vehicle data to understand
market trends and pricing patterns.

The analysis covers vehicle age, selling price, present price, kilometres
driven, fuel type, seller type, transmission and ownership.

## Objectives

- Analyze vehicle market data
- Study selling price and depreciation
- Analyze the effect of vehicle age and kilometres driven
- Identify popular vehicles
- Analyze fuel type and transmission trends
- Identify vehicles with higher-than-expected selling prices

## Dataset

The project uses the Car Dekho dataset.

- Records: 301
- Features: 9
- Unique Vehicle Models: 98
- Manufacturing Years: 2003–2018

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Analysis Performed

- Data cleaning and exploration
- Vehicle price analysis
- Depreciation analysis
- Age and mileage analysis
- Fuel type analysis
- Transmission analysis
- Car and two-wheeler analysis
- Expected vs actual selling price analysis

## Project Outcome

The project provides insights into vehicle pricing, depreciation,
market trends and factors related to selling prices.
